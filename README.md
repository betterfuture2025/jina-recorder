# 지나기록기 — 파트 1: 뼈대와 로그인

상담·회의 녹음 기록 시스템의 첫 파트입니다. 이 파트로 되는 것:

- 구글 로그인 (관리자가 등록한 지메일만 들어올 수 있음, 한 번 로그인하면 약 6개월 유지)
- 처음 설치 화면 (관리자 계정 + 구글 로그인 연결)
- 선생님 계정 관리 (추가, 관리자 지정, 접속 막기, 삭제)
- 설정 페이지 (API 키는 암호화해서 저장)
- 한국어·영어 전환, 휴대폰 홈 화면에 추가 (PWA)
- 녹음 화면 틀 (실제 녹음은 파트 2에서 연결)
- 전체 파트에서 쓸 DB 구조

## 올리는 방법

### 폰으로: 버튼 하나

[![Deploy to Cloudflare](https://deploy.workers.cloudflare.com/button)](https://deploy.workers.cloudflare.com/?url=https://github.com/betterfuture2025/jina-recorder)

1. 위 버튼을 누르고 Cloudflare에 로그인합니다 (계정이 없으면 그 자리에서 만들 수 있어요).
2. GitHub 계정을 연결하라고 나오면 연결합니다. 이 코드가 내 GitHub에 복사돼요.
3. 비밀값 두 개를 직접 정해서 넣습니다.
   - **ENC_KEY**: 16자 이상 아무 문장. 따로 적어 두고, 나중에 바꾸지 마세요.
   - **SETUP_KEY**: 처음 설치 화면에서 넣을 비밀번호.
4. **Create and deploy**를 누르면 몇 분 뒤 사이트 주소가 나옵니다.
5. 사이트 주소를 열면 "처음 설치" 화면이 나와요. SETUP_KEY, 관리자 지메일, 구글 로그인 정보를 넣으면 끝이에요. 구글 로그인 정보 만드는 법은 그 화면에 단계별로 나와 있어요.

DB 표는 사이트가 처음 켜질 때 스스로 만들어서, 따로 할 일이 없어요.

### 컴퓨터로

[Node.js](https://nodejs.org) (LTS 버전)를 설치한 뒤 이 폴더에서:

```
npm install
npm run setup
```

브라우저에서 Cloudflare 로그인만 누르면 DB 생성, 배포, 비밀값 등록까지 자동이고, 끝에 사이트 주소와 설치 코드가 나와요. 여러 번 실행해도 안전합니다 (ENC_KEY는 절대 바꾸지 않아요).

### 나중에 다른 계정으로 옮길 때

GitHub 저장소는 설정에서 **Transfer**로 넘기고, Cloudflare는 새 계정에서 버튼으로 다시 올린 뒤 DB를 옮기면 됩니다. 관리자를 늘리는 건 옮기지 않아도 **관리 → 선생님 계정**에서 바로 할 수 있어요.

### 막힐 때

| 메시지 | 할 일 |
| --- | --- |
| 구글 로그인 후 "아직 등록되지 않은 계정" | 관리 → 선생님 계정에서 그 지메일을 추가 |
| 설정 → 연결 테스트가 "맞지 않아요" | 구글 클라이언트 ID·보안 비밀번호를 다시 복사해서 저장 |
| 로그인 후 구글 화면에 "redirect_uri_mismatch" | 설정 화면의 리디렉션 URI를 구글 콘솔의 "승인된 리디렉션 URI"에 그대로 붙여 넣기 |

### 구글 동의 화면: 외부 vs 내부

- 선생님들이 **개인 지메일**도 쓰면 → **외부**를 고르고 **앱 게시**까지 누르세요. 로그인에 이름·이메일만 쓰기 때문에 구글 심사는 필요 없습니다.
- 모두 **센터 구글 워크스페이스 계정**만 쓰면 → **내부**를 골라도 됩니다.

어느 쪽이든 실제로 들어올 수 있는 사람은 이 사이트의 선생님 계정 목록에 있는 사람뿐입니다.

## 나중에 코드를 고친 뒤 다시 올리기

```
npm run deploy
```

## 폴더 구조

| 위치 | 내용 |
| --- | --- |
| `src/index.js` | 서버 입구, 주소별 처리 |
| `src/auth.js` | 구글 로그인, 로그인 유지 |
| `src/admin.js` | 처음 설치, 선생님 계정, 설정 저장 |
| `src/settings.js` | 설정 항목 목록 (새 파트는 여기에 항목만 추가) |
| `src/crypto.js` | API 키 암호화 |
| `public/` | 화면 (app.js, i18n.js 문구, styles.css) |
| `schema.sql` | DB 구조 (전체 파트용) |
| `scripts/setup.mjs` | 자동 설치 스크립트 |

## 내 컴퓨터에서 미리 돌려 보기 (선택)

`.dev.vars.example` 을 `.dev.vars` 로 복사해 값을 넣고, 한 줄 `DEV_LOGIN=1` 을 더한 뒤:

```
npm run dev
```

`http://localhost:8787` 에서 열립니다. `DEV_LOGIN=1` 이면 구글 없이 `/auth/dev-login?email=등록된메일` 로 로그인할 수 있습니다 (내 컴퓨터에서만 작동, 실제 사이트에서는 꺼져 있음).
