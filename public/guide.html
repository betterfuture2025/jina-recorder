1

홈 화면에 추가하기

한 번만 하면 앱처럼 바로 열리고, 로그인도 약 6개월 유지돼요.

아이폰 (사파리)

  1. 사파리에서 사이트 열기
  2. 아래쪽 공유 버튼 누르기 (네모에 위 화살표)
  3. 홈 화면에 추가 누르기
  4. 오른쪽 위 추가 누르기

안드로이드 (크롬)

  1. 크롬에서 사이트 열기
  2. 오른쪽 위 ⋮ 누르기
  3. 앱 설치 또는 홈 화면에 추가 누르기
  4. 설치 누르기

홈 화면에 지나 얼굴 아이콘이 생기면 끝이에요.

2

로그인하기

셋 중 편한 걸로 하세요. 어떤 방법이든 같은 곳으로 들어가요.

가장 쉬워요

이메일 + 비밀번호

가입할 때 정한 이메일과 비밀번호를 넣어요.

비밀번호 없이

이메일 인증번호

"인증번호로 로그인"을 누르면 메일로 6자리가 와요. 그걸 넣어요.

녹음하기

휴대폰을 탁자 가운데 놓고 평소처럼 이야기하면 돼요.

  1. 큰 빨간 버튼 누르기

    "바로 녹음"은 누르자마자 시작해요. 먼저 정하고 싶으면 아래 혼자 메모 · 회의 · 상담 중에 고르세요.

    학부모님께 녹음한다고 말씀드리고 체크한 다음 녹음 시작을 눌러요.

  4. "끝내고 저장하기" 누르기

    마지막 조각이 올라가는 동안 잠깐 기다리면 기록 화면이 저절로 열려요.

    예: "하윤이 어머님 상담". 종류도 여기서 바꿀 수 있어요.

5

선생님 관리관리자

왼쪽 위 ☰ 메뉴 → 선생님 계정을 눌러요. 홈 화면의 관리자 페이지 카드로도 들어갈 수 있어요.

  1. 가입 신청 승인

    새 신청은 맨 위에 숫자와 함께 떠요. 승인을 누르면 바로 들어올 수 있어요.

  2. 직접 추가하기

    아래 계정 추가에 이름·영어 이름·직책·전화번호·이메일을 넣어요. 비밀번호를 정해 주면 본인에게 알려 주세요.

  3. 비밀번호를 잊었다고 하면

    그 선생님의 정보 수정 → 새 비밀번호 정해 주기에 넣고 저장 → 본인에게 알려 주기.

  4. 그만둔 선생님은

    "접속 막기"를 누르세요. 기록은 그대로 남고, 로그인만 못 해요.

6

인증번호 메일 켜기관리자 · 한 번

"이메일 인증번호 로그인"을 쓰려면 한 번 해 두세요. Gmail 하나면 돼요.

  1. Gmail에 2단계 인증 켜기

    구글 계정 → 보안 → 2단계 인증. 이미 켜져 있으면 건너뛰어요.

  2. 앱 비밀번호 만들기

    아래 페이지를 열고 이름에 "지나기록기"를 넣고 만들기.
    구글 앱 비밀번호 열기

  3. 설정에 붙여 넣기

    ☰ 메뉴 → 설정 → 이메일 발송: Gmail 고르기 → Gmail 주소와 16자리 넣기 → 저장.

  4. 테스트 메일 보내기

    메일이 오면 끝이에요. 로그인 화면에 인증번호 로그인이 나타나요.

자주 묻는 것

마이크를 허용하라고 나와요

아이폰: 설정 › 사파리 › 마이크 › 허용. 안드로이드: 주소창 옆 자물쇠 → 권한 → 마이크 허용.

글자가 안 나왔어요

녹음은 저장돼 있어요. 기록을 열고 다시 받아쓰기를 눌러 보세요.

아이폰에서 녹음이 멈췄어요

아이폰은 화면이 꺼지거나 다른 앱으로 가면 녹음이 멈춰요. 끝날 때까지 이 화면을 켜 두세요. 멈추기 전까지 녹음된 건 저장돼 있어요.

관리 메뉴가 안 보여요

관리자에게만 보여요. 관리자에게 "관리자로" 바꿔 달라고 하세요.
